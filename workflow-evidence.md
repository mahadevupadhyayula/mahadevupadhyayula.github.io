    <p class="section-eyebrow">How I decide whether a workflow is worth building</p>
    <h2 id="worth-building-title">Start with the current cost, then test one bounded workflow.</h2>
    <p>I start with the current cost: volume, review time, rework, exceptions, and downstream risk. We test one bounded workflow, then decide whether to scale, refine, or stop based on agreed operating measures.</p>
