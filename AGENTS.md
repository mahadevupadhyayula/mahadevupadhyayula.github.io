# AGENTS.md

## Project goal

This is Mahadev Upadhyayula’s personal website. The current goal is to reposition it from a general Product Manager portfolio into a freelance AI automation conversion site.

Primary positioning:
Mahadev builds human-approved AI workflow systems for B2B teams, including CRM hygiene, lead research, content automation, and custom AI workflow prototypes.

## Copy principles

- Write for buyers, not recruiters first.
- Be specific and concrete.
- Prefer “CRM notes,” “lead research,” “content briefs,” “validated workflows,” and “human approval” over generic AI language.
- Avoid hype words like “AI magic,” “revolutionary,” “cutting-edge,” or “agentic transformation.”
- Keep paragraphs short and scannable.

## Design principles

- Premium B2B SaaS feel.
- Dark navy / near-black backgrounds.
- White text.
- Electric blue accents.
- Rounded cards.
- Clear CTA buttons.
- No generic robot imagery.
- Keep mobile readability strong.

## Engineering rules

- Do not add dependencies unless explicitly required.
- Preserve existing routes unless asked to rename them.
- Reuse existing layout/components/styles where possible.
- Keep changes small and reviewable.
- Run the project’s build command before final response.
- Report changed files and verification results.

## Done means

A task is complete only when:
- The requested content/UI change is implemented.
- Existing important routes still work.
- Build passes or any failure is clearly explained.
- The final response includes changed files and verification steps.
